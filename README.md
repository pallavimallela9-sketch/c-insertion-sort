# Insertion Sort in C

## Description

This program sorts the elements of an array in ascending order using the Insertion Sort algorithm.

Insertion Sort builds the sorted array one element at a time by placing each element in its correct position.

## Example

### Input

```text
45 12 78 23 9 34
```

### Output

```text
9 12 23 34 45 78
```

## Concepts Used

* Arrays
* Sorting
* Insertion Sort
* Nested loops
* While loop
